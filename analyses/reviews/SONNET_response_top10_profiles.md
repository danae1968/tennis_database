## Required
1. **Hold/break "trade-off" is selection (Berkson's paradox): FIXED.** Main title is now "Top players get there by different routes: some serve best, some return best". The README's short answer no longer leads with the correlation; it says plainly that the top-10 pattern comes from selecting on hold + break. New appendix figure A1 (`hold_vs_break_all_players.png`) shows all regular players with the top 10 highlighted, and `results/selection_check.csv` has the numbers. Reproduces the reviewer's table: WTA all regulars -0.11 (CI -0.33 to 0.12), top 10 -0.77, best 10 by sum -0.86; ATP -0.27, 0.02, -0.25. README states that the ATP value (-0.38 -> 0.02 when Sinner was added) is not meaningful with 10 players. Before: "serving and returning trade off, -0.77 / -0.38"; after: "only weakly related across the tour (-0.11 / -0.27)".
2. **Pressure points vs the tour gap and multiplicity: FIXED.** Each gap is now compared with the tour-average gap (z test on the bootstrap SD) and **all comparisons are Holm-corrected together**: 130 = 40 on tour data + 90 on charted key points (`results/pressure_tests_holm.csv`). Result: 10 uncorrected p < 0.05 (about 6.5 expected by chance), **0 after Holm**. Tiafoe +5.4 (p 0.005, Holm 0.63), Svitolina +5.7 (p 0.007, Holm 0.90, now mentioned), Zverev -5.9 (p 0.047, Holm 1.0). The README conclusion is now "top players perform under pressure about as their normal level predicts; no player stands out reliably". The reviewer's Holm p for Tiafoe was 0.22 over 40 tests; mine is 0.63 because the family is larger (130); both are far from significance.
   - **Partial decline:** charted key-point tests are restricted to players with at least 10 charted matches. With 2-6 charted matches the match bootstrap SD is degenerate (Shelton, 2 matches, gave p about 1e-11, Auger-Aliassime with 6 matches p about 2e-5), which would have produced false "significant" results. This is documented in the README.
